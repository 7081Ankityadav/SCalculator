# SCalculator

A lightweight calculator built with HTML, CSS, and vanilla JavaScript. It runs directly in a web browser and does not require any dependencies or a build step.

## Features

- Addition, subtraction, multiplication, division, and remainder
- Decimal number input
- Clear (`AC`) and delete (`DEL`) buttons
- Division-by-zero error handling
- Responsive layout for small screens

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Project files

- `index.html` — calculator structure
- `app.css` — calculator styling
- `app.js` — calculator behavior

## Publish with GitHub Pages

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings** and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the project and the `/ (root)` folder, then save.

GitHub Pages will provide a URL for the published calculator once deployment completes.
